# Hero renders

Placeholders. Replace these three files in place — same names, same paths — and
the homepage picks them up with no markup change:

    jersey-01.png   labelled "Classic" in the hero
    jersey-02.png   labelled "Bold"
    jersey-03.png   labelled "Retro"

Render or shoot them at a 4:5 portrait crop (the placeholders are 1000×1250) on
the same pale studio sweep the concept generator uses. The page is dark and the
panel behind each image is #eef1f4, so a light ground is what makes the jersey
look like it is standing on the panel rather than pasted onto it.
